# Анкета студента для родителей → Balazhan

Публичная форма (GitHub Pages) для родителей. Ответы попадают в Google Таблицу «Анкеты родителей — Balazhan»,
а обработчик создаёт студентов в кабинете куратора https://balazhan.nedb.kz (соцпаспорт + наблюдения куратора).

**Ссылки для родителей**
- 1 курс · Т110 — https://leonistr.github.io/balazhan-anketa/?g=T110
- 3 курс · ПО306 — https://leonistr.github.io/balazhan-anketa/?g=PO306

## Как устроено
1. `index.html` + `js/app.js` — форма. Поля и варианты ответов взяты из официальной формы сайта
   (`GET https://balazhan.nedb.kz/api/forms/social-passport`, `tools/build_schema.py` → `js/schema.js`).
   Условные поля как на сайте: «Наличие родителей» при «Неполная семья»; «Которым по счету» и разбивка по возрастам
   после «Количество детей»; «Основания повышенного внимания» при соответствующей соцкатегории; «Уточните» у «Другое»;
   страна / паспорт / дата рождения у иностранного гражданина.
2. `js/config.js` — **единственная настройка**: `ENDPOINT_URL` = URL веб-приложения Apps Script (`…/exec`).
3. `apps-script/Code.gs` — веб-приложение при таблице: принимает анкеты (защита от дублей по ИИН, LockService),
   отдаёт обработчику новые строки и принимает статусы (секрет `WORKER_TOKEN` в листе «Настройки»).
4. Обработчик: `worker/core.js` (общая логика) и
   - `worker/balazhan-anketa.user.js` — userscript для Tampermonkey: работает в браузере куратора, пока открыт кабинет;
   - Node-обработчик на сервере (`/workspace/balazhan-worker`, не в репозитории).

## Развёртывание Apps Script
Таблица → Расширения → Apps Script → вставить `apps-script/Code.gs` → сохранить → выполнить `setup` (выдать доступ) →
Развернуть → Новое развертывание → «Веб-приложение», выполнять от имени «Я», доступ «Все» → скопировать URL → вставить в `js/config.js`.

Наблюдения куратора, которые проставляются автоматически: «Изменений не наблюдается», «Стабильная, положительная среда»,
«Хорошие» ×3, «Не наблюдались» ×2, трудные ситуации — «Другое: Ничего», заключение — «Другое: Норма».
